# 日程助手(ScheduleAssistant)

一个**本地优先**的安卓日程 App:手动建日程对标小米日历,自动从「大段文字通知 / 图片通知」里生成日程,并用**聊天式通知 + 闹钟 + 倒计时**提醒你。

> 没有服务器、没有账号、不申请任何短信权限。数据只存在手机本地的 SQLite 里。

---

## 一、这个 App 解决什么问题

| 需求 | 实现 |
|---|---|
| **基础功能:手动安排日程(参考小米日历)** | 「创建日程」页完全对标小米日历:顶部四个 Tab(日程/生日/纪念日/倒数日)、智能输入框、全天开关、开始/结束时间、重复、提醒、**闹钟提醒**、**倒计时提醒**、备注、日历账户、时区。另有日程列表页与月视图。 |
| **① 从大段文字通知、图片通知自动生成日程** | 用 `NotificationListenerService` 读取其他 App 的通知:标题、正文、BigText、多行文本、聊天消息(MessagingStyle,含图片消息)、大图。文本走**中文语义解析**,图片走**本机离线中文 OCR**(ML Kit 打包版,不需要联网、不需要 API Key)。识别结果默认进「待确认」页,可设置高置信度自动加入。 |
| **② 给我的手机发信息提醒我(QQ/微信那种)** | 提醒用 `MessagingStyle` 构建 —— 系统会把它渲染成**聊天消息**(出现在消息区、带发送者头像和气泡),而不是普通应用通知。另可选「闹钟提醒」(锁屏全屏响铃)和「倒计时提醒」(常驻通知栏倒计时)。**全部在本机完成,不产生任何费用。** |

### 还能识别这些(不止通知)

**所有入口都收在右下角的「+」里**,点一下弹出面板(都不需要存储权限):

| 入口 | 说明 |
|---|---|
| **手动新建日程** | 和小米日历一样自己填 |
| **新建便签** | 随手记点什么(和日程相互独立) |
| **相册图片识别** | 系统照片选择器选图 → 本机离线 OCR 识别 |
| **拍照识别** | 直接拍海报/会议通知 → 识别 |
| **文件识别** | **PDF / Word / Excel / PPT / txt** → 抽取正文(PDF 先读文本层,扫描件再渲染成图 OCR) |
| **粘贴文字识别** | 把聊天记录、公告粘进来 |

另外:
- **消息里带链接**:自动联网抓取网页正文一起解析(报名页、公告的时间常常只在网页里),链接同时存进备注;
- **系统分享**:在微信/邮件/文件管理器里「分享 → 日程助手」,文字、图片、文档都能直接识别。

## 二、界面:三个页面

底部导航只留 **3 个**,其余收进右上角图标:

| 页面 | 内容 |
|---|---|
| **日程** | 默认只完整展开**今天 + 明天**;之后的和过去的都**折叠**成一行(点一下才展开)。右上角有 📅(切月历视图)和 ⚙️(设置) |
| **课程表** | 按周次的课表格子(7 天 × 12 节):点空格添加、点课程编辑;右上角「导入」可**自动识别课表**(见下) |
| **记录** | 两个分段:**待办**(任务清单)与**便签**(随手记) |

### 日程页的主次

- **今天 / 明天**:完整展开,一眼看清
- **「之后 N 条 · 后天起」**:折叠,点开才展开
- **「更早 N 条 · 已过去」**:同样折叠
- 待确认日程以卡片形式出现在顶部(有才显示)

### 课程表导入(.ics 最准)

课程表页右上角 **「导入」**:

- **文件(.ics 等)— 最准**:如果你在用 **WakeUp课程表**(它能登录学校教务系统),
  在 WakeUp 里**导出课表(.ics)**,用这个入口选进来 —— 课程名/老师/教室/星期/节次/周次
  **全部精确还原**,不靠 OCR、不需要登录任何系统。
  导入时还会**自动对齐节次时间和学期起始日期**(合并,不会覆盖你已有的节次)。
  同一个入口也会自动识别 WakeUp 的 `.wakeup_schedule` 备份文件,以及 Excel/Word/PDF 等普通文档。
- **相册图片 / 拍照**:课表截图 —— 走 OCR + **网格还原**(用文字坐标判断每个格子属于星期几第几节),
  比起"按阅读顺序读文字"准得多;若配了多模态模型的 Key 则优先用大模型。
- **粘贴文字**:直接把课表文字粘进来。

识别完会**先给一份预览**(周几、第几节、周次、上课地点),确认后选「**覆盖原课表(N 门)**」或「**追加**」再写入。
**同一门课永远同一个颜色**(按课程名取色,手动选过则以手动为准);**非本周的课半透明并标「非本周」**。

本地规则支持的写法(离线也能用):
```
高等数学 周一 1-2节 1-16周 A301 张老师
周二 3-4节 大学物理 实验楼B203
周三 5-6节 英语听力 3-9周 单周 外语楼302
```

> **为什么不做"输学号密码自动爬"**:每个学校的教务系统都不一样(正方/URP/强智/青果/一网通办…),
> 还常有 **WebVPN + 钉钉扫码** 这类登录方式(内置 WebView 打不开,实测白屏),
> 把账号密码存进第三方 App 也有真实风险。
> **正确姿势是"让专门做课表的 App 去登录,我只读它的导出"** —— 这就是 .ics 导入。
>
> 也试过 WakeUp 的**分享口令**接口(`i.wakeup.fun/share_schedule/get`),但官方已在服务端锁死
> (只允许自家 App 调用,第三方一律返回「当前版本过低」),所以走导出文件这条路。

### 功能自检

设置 → **功能自检**:一键检查 13 项并逐条显示结果(通过/警告),不用靠猜哪里没配好:

节假日数据(离线) · 农历算法 · 月历节假日显示 · 数据库 6 张表 · **当前生效的提醒铃声** · 通知权限 ·
通知使用权(自动识别日程) · 精确闹钟权限 · **全屏通知权限(闹钟弹窗)** ·
**数据库体积/日志条数** · **待办抽取(拿示例句现场跑一遍)** · 日程解析(示例句现场跑一遍) · 课程表与上课提醒

### 待办(任务)

和日程的区别:**日程有明确开始时间,待办只是"要做的一件事"**。

例:群里老师说「明天会发一张表格下来需要我们填写,**准备好一寸照片**」
→ 日程:明天的事情;**待办:准备一寸照片**(自动加进待办清单)

- 云端解析时由大模型判断哪些是待办;离线时用本地规则(命中「记得 / 别忘 / 需要 / 准备 / 填写 / 提交 / 打印 / 登记 / 检查 / 带上…」这类词,且**没有明确时间**的句子)
- **默认只从聊天/工作类通知里抽**(钉钉 / 微信 / QQ / 短信 / 飞书 / 邮件)——可关
- **营销与预警文案自动过滤**:确认收货、优惠券、满减、注意防范雷电、清理垃圾这类一律不抽
- 一条通知最多抽 2 条;同一个应用每天最多加 5 条(可调)
- 待办**不用确认**,直接进清单(多一行风险很低),同时发一条「已加入待办:X」通知,带**撤销**按钮
- 支持勾选完成、标记重要、截止时间(无/今天/明天/本周末)、删除、一键清空已完成

### 数据与备份

设置 → **数据与备份**:

- **导出备份(JSON)**:把日程 / 便签 / 课程 / 待办导成一个文件;换手机或重装前建议导一份
- **从备份恢复**:**追加式**导入 —— 标题+时间相同的不会重复添加,不覆盖现有数据
- 不导出导入日志(纯诊断);**API Key 不写进备份文件**
- 设置里直接显示**数据库大小**,涨得离谱就说明该清日志了

### 内置过滤(减少噪音)

- **系统类通知不解析**(可关):系统时钟、系统更新、桌面、设置、安全中心 —— 实测时钟自己的「闹钟」曾被当成一条新日程
- **导入日志最多保留 400 条**:早期版本会把"常驻通知(音乐/下载)"也记进日志,实测涨到 **4.5 万条 / 8.7MB**;现在这类跳过根本不记,并自动裁剪旧记录
- 自动去重:同一标题 12 小时内不重复加入

### 节假日与农历

- 节假日数据**随 APK 打包**(`assets/holidays.json`),离线可用;当前覆盖 **2025–2026**(2027 官方尚未公布,界面会提示「该年节假日数据未收录」)
- 农历为内置算法(1900–2100,支持闰月),传统节日含春节/元宵/端午/七夕/中秋/重阳/腊八/小年/除夕
- 数据来源:holiday-cn(依据 gov.cn 每年发布的放假通知)

### 课程表与上课提醒

- 周次按「学期第一周的周一」计算(设置 → 课程表设置里可改,或一键「设为本周」)
- 节次时间可自定义(默认 12 节:上午 4 / 下午 4 / 晚上 4)
- **上课提醒**:每天按当天课表排精确闹钟,发一条和日程一样的**聊天式通知**(走闹钟音量,静音也响);每天 00:05 自动续排次日,开机/打开 App 也会重排
- 提醒铃声跟随 设置 → 提醒 → 提醒铃声(默认「闹钟音」,静音也响)

### 提醒行为

- 到点发**聊天式通知**(QQ/微信那种消息样式),可选**闹钟全屏响铃**与**倒计时通知**;
- **提醒铃声可配**(设置 → 提醒):默认「**闹钟音**」—— 通知渠道音频属性设为 `USAGE_ALARM`,**手机静音/振动时照样响**;也可切成「跟随系统通知音」或「静音」;
- **提前量可自定义**:编辑页 → 提醒 → 「自定义…」,想提前几分钟都行(3 / 45 / 60 / 1440…);
- **AI 自动判断提醒时间**:原文没写提醒时,大模型按任务类型给值(面试/考试/航班提前 1 小时,会议/上课 30 分钟,截止/报名提前 1 天…),可在设置里关掉;
- 建日程时如果「提醒时间已过」但日程还没开始 —— **会立刻补发提醒**,不会静默跳过;
- **任务完成**:列表里每条日程右侧圆圈点一下即完成(标题加删除线 + 绿色对勾),编辑页也有「标记为已完成」开关;完成后不再提醒并撤掉相关通知;
- 删除或标记完成日程时,提醒/倒计时/闹钟通知都会一并撤销;App 启动时也会清理「已完成/已结束」日程的残留通知。

> 关于短信:按你的要求,**已彻底移除短信功能** —— 不申请 `SEND_SMS`/`READ_SMS`/`RECEIVE_SMS` 任何权限。你原本说的「发信息提醒我」现在由上面的聊天式通知实现,效果就是 QQ/微信 那种消息提醒,免费且不用运营商。

## 四、首次使用:一定要走一遍「权限向导」

国产 ROM(尤其小米 HyperOS)对后台管得非常严,少开一项提醒就会不准时甚至不响。

打开 App → 设置 → **权限向导**,依次开启 6 项:

| # | 项目 | 为什么必须开 |
|---|---|---|
| 1 | **通知使用权** | 不开就无法读取别的 App 的通知,「自动生成日程」整个功能失效 |
| 2 | 通知权限 | 不开则提醒弹不出来 |
| 3 | **精确闹钟** | 不开的话 Android 会把提醒推迟几分钟到几十分钟 |
| 4 | 后台运行 / 电池不优化 | 否则锁屏一段时间后闹钟和监听被系统冻结 |
| 5 | 全屏通知(Android 14+) | 「闹钟提醒」要在锁屏全屏弹出就靠它 |
| 6 | 自启动(小米/华为必开) | 小米:设置 → 应用设置 → 应用管理 → 日程助手 → **自启动**打开,并把**省电策略**设为**无限制** |

向导页每一行都会显示当前是否已开启,右上角「刷新」可复查。

## 五、可选:配置大模型(图片识别 + 更强理解)

**不配置也完全能用**:文本解析走内置的中文规则引擎,离线可用,已通过 114 个中文时间语义测试用例(明天/下周三/大后天/9月13号/每晚11点到凌晨1点/提前15分钟/每月5号 …)。

配置后能带来两个提升:
1. **图片通知自动识别**(规则引擎做不到,必须靠多模态大模型);
2. 大段杂乱文字(如长段聊天记录、公告)的抽取更准。

设置 → 解析引擎,填三项即可(任何 **OpenAI 兼容**接口都行):

| 服务 | 接口地址 | 文本模型 | 图片模型 |
|---|---|---|---|
| **DeepSeek(本机现用)** | `https://api.deepseek.com/v1` | `deepseek-flash` | 同左(实测支持看图) |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | `qwen-vl-max` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | `glm-4v` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | `moonshot-v1-8k-vision-preview` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` | `Qwen/Qwen2-VL-72B-Instruct` |

> DeepSeek 目前提供 `deepseek-flash`(快)和 `deepseek-v4-pro` 两个模型,两者都可用于本 App。

**解析引擎模式(设置里可切)**

- **自动(默认,云端优先)**:配了 Key 且能联网 → **优先走云端大模型**;只有「API 请求失败(会先重试一次)/ 离线 / 没配 Key」才回退本地规则。图片同理:优先多模态大模型,失败才用本机离线 OCR 兜底。
- 只用云端大模型:强制走大模型,不用本地兜底。
- 只用本地规则:完全不联网,纯离线。

每次解析实际用了哪个引擎,都会显示在「待确认」卡片的标签上,也记在「导入日志」里;回退时卡片上会写明原因(例如「云端大模型请求失败,已回退本地规则(超时)」)。

## 六、功能细节

### 1. 自动生成日程的过滤规则(宁缺毋滥)

不是所有通知都会解析,避免把群聊闲话变成日程:

- 跳过常驻通知(音乐、下载进度)、分组摘要、本应用自己的通知;
- 文本太短(默认 < 12 字)且没有**时间词/事件词** → 跳过;
- 支持**包名白名单/黑名单**(例如只想监听微信);
- 同一条通知被系统反复更新时,内容没变就不重复解析;
- 同一段文本在 3 小时内不重复提示(时间窗口可配);
- 系统截图通知默认关闭,可在设置里打开(打开后截图即自动识别);
- 解析结果:
  - 置信度 < 0.45 → 直接丢弃(只记日志);
  - 0.45 ~ 阈值 → 进「待确认」页 + 发一条聊天式通知;
  - ≥ 阈值(默认 0.85,可调)→ 若开启「高置信度自动加入」则直接进日程表。

### 2. 支持的重复规则

永不 / 每天 / 每个工作日(周一至周五) / 每周X / 每月X号 / 每年 —— 提醒闹钟会随重复规则自动滚动排下一次。

### 3. 提醒的三种形态

| 形态 | 效果 |
|---|---|
| 聊天式通知 | 像 QQ/微信 消息一样出现在通知栏,带「稍后10分钟」「标记完成」按钮 |
| 闹钟提醒 | 到点**锁屏全屏响铃**(自动把闹钟音量拉满,振动,最长响 5 分钟),可「稍后10分钟」 |
| 倒计时提醒 | 常驻通知栏,显示距离日程开始还有多久 |

开机、应用更新、修改系统时间/时区后会自动重排全部提醒(否则 Android 重启会清空所有闹钟)。

### 4. 其它

- 分享即识别:任意 App 里「分享 → 日程助手」,或选中文字用「处理文本」菜单,自动解析成日程;
- 导入日志:每条被解析过的通知都留痕(原文、引擎、结果),排查「为什么没建上日程」;
- 深色模式 / 默认提醒 / 默认账户 等默认值可配。

### 本机开发时踩过的 Windows 坑(记录备查)

1. **`gradle.properties` 按 ISO-8859-1 读** —— 里面出现中文会乱码,所以带中文的路径一律用环境变量传。
2. **AGP 拒绝非 ASCII 工程路径** —— 见上面那条提示。

## 八、隐私说明(重要)

这个 App 需要「**通知使用权**」才能从通知里识别日程,请务必知道它的边界:

| 数据 | 去哪里 |
|---|---|
| 通知内容 | **只在本机处理**。是否记录、记录多少条都能在设置里看到(导入日志上限 400 条,可一键清除) |
| 通知/图片里的文字 | 默认**优先发给 LLM 接口**做理解 —— 用的是**你自己填的 API Key**、你自己选的接口地址 |
| API Key | **只存在本机** `SharedPreferences`,**不会随备份导出**、不会打印日志;设置页只显示掩码 |
| 短信/通讯录/定位/相册全盘 | **一律不申请**(没有任何 SMS 权限) |
| 云端大模型的开关 | 设置 → 解析引擎,可切成「只用本地规则」,那样**一个字都不会离开手机** |

**不上传任何数据到作者的服务器** —— 这个 App 没有作者的服务器,所有云端调用都是你直连你自己配置的接口。

## 十二、已知限制

- 农历与节日名(春节、中秋)不推算日期;不支持「每两周」「隔周」「每月最后一个周五」;
- 英文时间表达(next Monday / Sep 13)不支持;
- 地点是启发式识别(「在望京SOHO」可以,「在楼下那家店」不行);
- 图片识别优先走多模态大模型;没配视觉模型时退回**本机 ML Kit OCR + 网格还原**(见 `TimetableGridParser.kt`),
  截图质量差时会有误差 —— 课表导入更推荐 `.ics`;
- 通知里的图片:如果对方 App 只给了 `content://` 且没给读权限,可能取不到图,此时会退化为只解析文字(日志里能看到);
- 未做「写入系统日历」;日程存在 App 自己的库里。
